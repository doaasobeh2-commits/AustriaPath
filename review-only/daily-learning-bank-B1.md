# B1 Daily Learning Bank (90 cards)

### B1-001
**Category:** Schreiben
**Situation:** Sie schreiben eine formelle E-Mail an Frau Korma und möchten Informationen über eine Ausbildung.
**Question:** Which answer is better?
**A)** Ich schreibe Ihnen, weil ich mehr Informationen über eine neue Ausbildung brauche.
**B)** Ich schreibe Ihnen, weil ich eine neue Ausbildung machen möchte.
**Better:** A
**Reason:** In einer Informationsanfrage ist „mehr Informationen brauchen“ zielgerichteter — B klingt eher wie der Beginn einer Bewerbung.
**Source:** `modelsb1.js` → Modell 1, E-Mail A „Ausbildung als Traumberuf“
